# Cheatsheets

A small collection of practical, easy-to-scan references for tools and languages I use. Each
cheatsheet is a standalone Markdown file with examples and quick reminders, so you can browse it on
GitHub or keep it open alongside your work.

| Topic | What it covers |
| --- | --- |
| [Modern C++](cpp.md) | Language features and standard-library tools, from initialization and ownership to ranges, concurrency, and C++20/23 additions. |
| [Modern C++ metaprogramming](cpp-metaprogramming.md) | Templates, type traits, compile-time computation, SFINAE, concepts, and generic programming utilities. |
| [`git`](git.md) | Everyday commands for inspecting changes, staging, commits, branches, remotes, rebasing, and stashing, plus useful Zsh aliases. |
| [`vim`](vim.md) | Help, editing, text objects, registers, macros, buffers, and split windows. |
